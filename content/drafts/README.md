# Drafts

Markdown here is loadable at `/writing/<slug>` for rendering tests, but **never
listed** on the homepage Writing rail.

You can also keep a file in `content/posts/` with frontmatter `status: draft`
(or `unpublished` / `hidden`) for the same rail-hiding behavior.

Slug collision: a file in `content/posts/` wins over the same slug in this
folder.
